# 🔄 Identificador de Palíndromos

Aplicação web interativa desenvolvida durante os estudos de lógica de programação e JavaScript da Alura. O projeto analisa textos inseridos pelo usuário, remove espaços e pontuações indesejadas, e valida se a sequência forma um palíndromo perfeito.

---

## 🚀 Tecnologias Utilizadas

* **HTML5**[cite: 3]
* **CSS3**[cite: 3]
* **JavaScript (Vanilla)**[cite: 3]

---

## 🛠️ Funcionalidades

* **Verificação Inteligente**: Inverte a string fornecida e compara com o original para identificar palíndromos.
* **Tratamento de Texto**: Limpa caracteres especiais, espaços e formata o texto para garantir uma validação precisa.
* **Feedback Visual**: Exibe mensagens dinâmicas na tela informando se o texto digitado é ou não um palíndromo.
